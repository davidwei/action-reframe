1. Add a video project

Add video files to this server's workspace folder, then refresh. Existing projects appear below. Each video can have more than one target/project.

2. Prepare and approve

Open a project to draw ground-truth labels and choose analysis settings. Review its identity description here. “Approve description & mark ready” approves the current labels and settings as well. Changes require approval again. You can select several ready projects to queue together.

3. Overnight queue

One video runs at a time. Closing this page does not stop processing. Pause finishes the current video; queued jobs can be cancelled. Failed or interrupted jobs can retry using saved inputs and cached work. Start/resume also checks for interrupted runners after a restart.
